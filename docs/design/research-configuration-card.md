# 研究能力配置提示卡

## 决策

不新增 setup 或 doctor 斜杠命令。
每次扩展建立会话上下文时显示简短提示卡，包括首次启动、重载、新会话、恢复与分叉。
不采用首次提示去重、已读标记或持久化关闭偏好。
用户开始任务时收起本次卡片，下次加载重新展示最新本地配置状态。

## 已实现范围

- TUI 与 RPC 使用同一个字符串数组 widget；RPC 客户端负责展示 `setWidget` 事件。
- Print / JSON 无卡片、不等待交互、不向 stdout 写入额外文本。
- 未信任的项目只报告未检查，不读取研究配置。
- 状态包含 Context7、Grok、可选 Tavily、生效文件及本地编辑方式。
- 无文件时推荐用户级配置，已有项目文件时提示整文件覆盖关系，不合并密钥与 endpoint。
- Context7 无文件时匿名访问；文件损坏仍报错。
- 检查不联网、不调用模型、不写文件、不激活阶段、不向模型上下文注入消息。
- 卡片只输出固定字段名和路径，不输出配置值、服务地址、模型名、密钥或原始异常。
- 配置读取限制为不超过 64 KiB 的普通文件，非普通文件和超限文件明确拒绝。

## 明确不包含

本次不实现安全密钥输入向导、配置写入、网络验证、按需弹窗或原请求自动重试。
卡片不显示尚未实现的按钮，也不要求用户把密钥交给模型。
不改变研究 CLI 忽略 shell API 变量、项目整文件优先的现有语义。
不把研究服务配置作为普通任务或项目初始化的强制条件。
“已配置”只表示本地字段检查通过，不代表认证、网络、模型或服务能力正常。

## 验收

1. 每次 `session_start` 都重新投影卡片，包括连续 reload 和已配置用户。
2. `agent_start` 与 `session_shutdown` 只清理本组件的 widget。
3. 没有配置文件时，卡片给出缺失 Grok 字段及用户级路径，Context7 可采用匿名默认值。
4. 项目覆盖用户配置时不隐式补齐字段，损坏文件不回退。
5. 配置中的敏感值和原始错误不会出现在卡片中。
6. 初始化提示不注册新命令、不调用模型、不持久化提示、不改变工作流激活边界。
7. 非交互模式不读取提示卡配置、不弹窗、不影响协议输出。
