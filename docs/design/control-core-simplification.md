# 控制核心简化方案

本轮是普通开发任务。
目标是降低控制核心的修改成本，并明确现有保证的适用范围。

## 设计与范围

1. 将状态投影提取到 `src/workflow-status.ts`。
   状态机读取运行、任务、恢复和预算事实；纯函数生成 blockers、decisionBatch、continuation、队列及安全诊断。
   投影不接收数据库、Worker 或可执行回调，不能发起任务或改变状态。
   现有状态响应保持一致。
2. 将普通阶段和修复阶段重复的候选读取、哈希/UTF-8/路径校验及分段封存收敛到 `src/candidate-artifact.ts`。
   共用代码返回结构化工件事实或诊断；调用方继续决定普通越界纠错与修复权限扩展的不同处理，保留原有校验顺序、预算、取消、回滚和提交时机。
3. 运行已有真实任务评估，保留脱敏指标。
   Provider 不可用与工作流停滞、独立验收失败分开记录；预检和确定性测试不充当真实模型通过证据。

本轮不更换状态机、存储协议、依赖或隔离后端，也不引入通用恢复框架。
大型执行函数先移除已经重复的职责，后续拆分以具体变化需求为依据。

## 父模型与验收边界

本轮保留 Implement 父模型宿主工具，以便在已有授权内调查和修复环境；产品改动应通过控制面完成。
子 Worker 和控制面执行路径受代码约束，父模型属于信任根。
README 明确此范围，现有阶段切换测试验证工具恢复。
硬性收紧父工具会同时取消现有宿主环境修复能力，作为单独的行为变更处理。

结构化 ChangeContract 固定验收义务、路径、依赖和验证模式；自然语言目标是否被充分表达仍取决于验收设计。
已有评估在控制面之外运行独立结果检查，继续保留此边界。

## 验证与完成标准

- 状态投影保持已有恢复、审批批次、预算耗尽、队列和终态行为；架构测试检查依赖无环与状态转换权限边界，行为测试检查输入不变及状态结果。
- 普通与修复候选共用校验，仍区分可纠正格式错误、封存完整性损坏及写入范围扩展。
- 执行完整 `bun run verify`、AGENTS 和需求追踪检查，并运行真实 Linux 隔离回归与新进程 seed acceptance。
- 真实模型评估单独记录完成率、耗时、token、重复修订及用户介入；外部能力失败如实保留。

## 实施结果

- 状态机从 4,478 行降至 4,164 行，执行层从 4,385 行降至 4,181 行；两个控制核心共移出或去重 518 行。
  两个提取模块合计 527 行，四个文件净增加 9 行；收益是职责收敛，并非总代码量减少。
- 新增两个内聚模块，保持原有六个控制命令、状态输出、租约、恢复预算、事务时机与存储格式。
- 新增回归覆盖多段候选跨存储重开、当前权限约束旧候选、封存完整性与格式错误分类、无效 UTF-8、纯状态投影、稳定决策批次、预算耗尽和队列排序。
- 更新 README、AGENTS 和真实打包成员清单。

## 开发阶段精简

- 移除状态投影的精确导入列表断言，保留依赖无环、权限边界与状态行为验证。
- 删除重复的激活、阶段路由和提示原句断言；保留可执行命令示例、真实提示加载、参数展开，以及尚无执行等价物的关键指引检查。
- 两份评估汇总通过原始报告引用替代重复结果，详细 HTTP 观测、探测结果和宿主状态集中归档；逐字段重建核对通过，7 份原始 CLI 报告字节不变。
- 发布 [单任务 PlanDraft 示例](../../config/plan-draft.example.json)，并从 Design 提示直接链接。
  示例包含结构化 Gate A 合同、现有测试证据和 Red/Green 边界，复用现有 Design 预检集成测试验证其合法性。
- 编译器根据任务 ID 补齐草稿省略的 `tracking`；显式填写错误仍拒绝，已封存计划仍要求完整字段，现有计划字节和哈希不变。
  权限、验证命令和恢复次数继续显式声明，已批准的 `changeContract` 沿用现有继承机制。

本次精简的验证采用现有本地测试与发布检查，未重新运行真实模型评估；耗时和首次计划预检通过率的改善仍待后续同条件测量。
`bun run verify` 通过：738 项测试通过、14 项条件跳过，类型/语法、格式及 73 成员真实打包检查通过；AGENTS 索引、64 条活动需求/场景追踪及 `git diff --check` 通过。

用户随后授权的 [真实模型评估](optimization-live-evaluation.md) 已完成三次有界运行：单任务独立验收通过，多任务仍未在 10 分钟内完成端到端流程；三次均无宿主模型错误或 SDK 超时诊断。
根据真实预检复现，在 Design 提示中补充了现有测试归属字段的三行说明，保留原有严格校验；源码查阅减少，但整体提速尚未证实。
