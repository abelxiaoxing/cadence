# Lightweight Distribution and Retirement

## Actual shipped surface

`provenance/package-members.json` independently specifies **34 unique regular archive members**, including **16 source files**.
It is a reviewed policy, never generated from the archive being audited.
`package.json` exposes only `./src/index.ts` as the Pi extension and `./skills` as independent skills; no prompt aliases, task RPC/tool or second executor.
Members include three fixed Agents, research/check examples, MIT license and pi-subagents notices/license.
Tests, scripts, provenance, Trellis files, private diagnostics and retired helpers do not ship.

`scripts/package-audit.mjs` checks safe regular tar members, uniqueness, checksums, exact membership, every body against reviewed source and all Agent provenance hashes.
It rejects traversal/control/ambiguous names, link/special/extended types, source links, duplicate manifest entries, drift and pin mismatch before extraction.
A count/listing alone cannot replace this audit.
`scripts/pack-check.mjs` performs a real `bun pm pack`; retain a separate real-pack route for qualification too.

## Canonical executable paths

`scripts/build-operator.mjs` builds the sole generated `src/operator-cli.mjs` from `operator-cli-entry.mjs` and local dependencies; `--check` compares exact generated bytes.
`src/sdk-worker.mjs` is maintained ordinary JavaScript and runs against installed peers, with no TypeScript/source-tree fallback or CLI startup.
Pi itself loads the extension TypeScript.
Extracted fixtures use actual package bodies in node_modules layout and trusted existing peer links, not package-manager installation or automatic downloads.

Operator interface:

```text
node <cadence>/src/operator-cli.mjs doctor|runs [workspace]
```

Default command is doctor; default workspace is cwd; extra/unknown arguments refuse with fixed `operator-refused` JSON and exit 1.
`inspectConsumer` returns schema `cadence-assistant-doctor/1`, root/cwd, task count, check name/timeout list, `checkStatus: "not-run"`, coordination and an observation notice.
`inspectRuns` returns `cadence-assistant-history/1`, bounded task summaries, historical check metadata/review and running-as-interrupted projection.
Neither invokes controller/runner, recovery, migration, Git mutation or installation; absent stores stay absent.
Stored statuses are not revalidated check freshness.

## Retirement and preservation

All **93** inventoried obsolete source owners are absent from the reviewed replacement, including compiler/scheduler/seal/transaction/SQLite/native-helper/workspace-worker runtime.
Do not retain them behind new UI or copy them into generated bodies.
[Independent review](../../tasks/10-06-cadence-retirement-distribution-qualification/research/lightweight-independent-review.md) audits 194 old test files and **2499 static title rows** (2354 test + 145 suite declarations), not executed test counts or one-to-one equivalence.
Retained/ported intent and superseded mechanisms have explicit dispositions in task research; fewer tests alone prove nothing.
Historical **5547 passed / 5 failed / 9 skipped remains FAILED/SUPERSEDED**, never a new pass.
Old preimages/reports and [pre-refresh specs](../../tasks/10-06-cadence-retirement-distribution-qualification/research/retired-certified-specs/manifest.json) remain historical evidence.

Consumer task/history/config/session/OpenSpec/Git bytes and uncertain legacy resources are not retirement targets.
No old approval is imported, no old lock cleared and no old store reset.
Only the explicitly confirmed new stale-lock recovery described in [storage](./database-guidelines.md) exists.

## Independent content and qualification

Preserve `context7-auto-research`, `grok-search`, explicit-request-only `git-commit`, nonactivating startup summary and missing-only user `.env` template.
Agent text/pins (`provenance/adapted-modules.yaml`) and exact body tests change together when an adaptation is reviewed.
Runtime hashes package-local Agent content; it does not interpret provenance YAML as authorization.
Cadence stays MIT with pi-subagents attribution; borrow Trellis ideas only, not AGPL source/templates or a runtime dependency.

`test/distribution.test.mjs` exercises source/extracted entry/operator, absent/corrupt/trap consumers, nonterminal CLI and actual extracted SDK tool/auth cycle.
`test/terminal-integration.test.mjs` runs four production PTYs; [quality](./quality-guidelines.md) defines evidence limits.
The reviewed 205/0/0 local suite and exact pack audit do not establish unexecuted OS, manager, human or paid-provider release lanes.
Node/Pi qualification records actual identities/capabilities without version predicates; engine/peer/dev metadata are not rewritten to encode a release lane.
No passing gate authorizes commit, push, publication, task archive or consumer cleanup.
