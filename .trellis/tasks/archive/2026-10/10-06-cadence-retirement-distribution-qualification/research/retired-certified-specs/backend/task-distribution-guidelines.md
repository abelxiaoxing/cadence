## Sole package entry and non-destruction

`src/index.ts` composes `registerTaskCompletionShell` and the child recursion guard.
Discovery/startup register inert capabilities and independent configuration presentation only.
Only a current idle raw terminal `/cadence` invocation can start task interaction; `hasUI` alone does not admit RPC.
Quoted commands, ordinary input, queued/synthetic/replayed input, old markers and imported history do not grant authority.
The package ships no workflow prompt alias, upstream CLI, RPC evaluator or second executor.

Existing consumer OpenSpec, `.pi`, sessions, config, Git index, ignore files, private stores, sealed reports and uncertain native resources are not reset, migrated as approval or deleted.
Readonly legacy decoding is bounded, immutable context under the shared fence: no sidecars, live resource/apply tables or uncertain ownership may be treated as quiescence.
A missing observation target stays absent; malformed/partial/future/linked state fails closed.

## Scenario: explicit development evidence and exact archive boundaries

### 1. Scope / Trigger

Use this contract when changing package resources, traceability maps, operators or CI qualification.
The tools are development-only and are not runtime permission providers.

### 2. Signatures

```sh
node scripts/traceability-check.mjs --map <owned-map.json> [--require-passed]
node scripts/pack-check.mjs
node src/operator-cli.mjs doctor|runs [consumer-root]
```

`auditPackage(archive, sourceRoot, expected, provenanceRoot?)` checks a real gzip/tar archive against a reviewed explicit member array.
`inspectRuns(root)` returns `authority: context-only`, `stale: true`, layout, at most32 minimized task rows, usage, truncation and a legacy-presence label.
No title/business prose, approval receipt or mutable task controller is returned.

### 3. Contracts

A map has only `formatVersion: 1`, `prd`, `criteria` and `releaseLanes`.
Criteria bind exact checked PRD acceptance IDs, parent IDs, required flags, status and nonempty verification arrays.
Each verification has unique `id`, owned `path`, actual `assertions`, explicit `inputPaths`, required flag, closed status and evidence array.
Declared inputs include the check path, package.json and PRD; current G6 map additionally lists every reviewed shipped body and provenance input.
Passed evidence has bounded argv `command`, exitCode0, outcome passed, exact lane/platform/runtime, current input digests, absolute external log locator and SHA-256.
The checker authenticates log bytes but does not adjudicate prose, rerun tests or infer physical-human/native completion from text.
Release lanes bind actual check IDs, exact lane and platform, but have no `runtime` field or version predicate.
Evidence `runtime` remains mandatory, bounded and actual; distinct observed Node/Pi identities may satisfy the same lane without relaxing current input/log/exit checks.
Unavailable evidence stays nonpassing.

### 4. Validation & Error Matrix

- Missing explicit map, unknown fields/statuses, empty criteria/required coverage or duplicate IDs → nonzero bounded `traceability-*` error.
- Missing/dangling/escaped/linked/oversized/nonregular path or nonexistent assertion → nonzero path/assertion error.
- Missing/partial/nonzero-exit/stale/log-mismatched evidence → nonzero evidence error, including outside release mode for falsely passed records.
- Required planned/failed/blocked/unavailable or inapplicable lane under required-passed → nonzero refusal.
- Archive duplicate/unsafe member, link/special/PAX type, invalid checksum/trailer/member set or body/pin drift → nonzero `package-audit-*` error.
- Absent task state → empty absent context page, no mkdir/store allocation; malformed state → bounded refusal, no migration/reset.

### 5. Good / Base / Bad Cases

Good: a curated map names actual assertions, current source/package inputs and independently reviewed waited evidence; release mode checks every required applicable lane.
Base: an all-planned/unavailable map is reference-valid but cannot pass required-passed.
Bad: a green file count, fabricated passed flag, source fallback, old receipt or Linux-only run is presented as installed/native/all-platform permission.

### 4. Validation & Error Matrix
