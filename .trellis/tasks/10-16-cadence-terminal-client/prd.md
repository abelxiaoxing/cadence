# W5 — Complete native terminal service client

## Goal

Own this work package within the [complete parent redesign](../10-16-cadence-webui-terminal/prd.md).
This is internal engineering organization, not a phased product release.

## Requirements and Prerequisites

Parent requirements: **R1–R2, R4–R7, R12–R14**.
Parent acceptance: **AC1,4–9,12,18–20,22**.
All parent preservation, explicit-authority, reuse and truthful-evidence constraints apply.

Prerequisites: W1 typed client available; W4 full action API integrated for real terminal qualification.
UI fixtures alone are insufficient.
Dependencies are explicit here; tree position is not a scheduler.
Status remains planning until final parent approval and this child is started.

## Acceptance Criteria

- **W5-AC1:** Complete native workflow uses the owner without browser or embedded fallback.
- **W5-AC2:** Raw entry, trust/idle, current dialog and exact-byte plan protections remain.
- **W5-AC3:** Return/navigation/quit detaches accepted work; explicit Cancel reports bounded settlement/unknown.
- **W5-AC4:** Native graph/message/tool/timeline/history/search/export uses identical IDs and coverage to browser.
- **W5-AC5:** Independent conversations/skills/startup stay nonactivating; owner absence gives explicit management guidance.

## Out of Scope

- Partial-product release or deferring core scope.
- Unrelated dirty files, archive/consumer cleanup, credential export or automatic Git/install/publication.
- Competing execution owners or duplicate protocol/projection rules.
- Runtime success claims based only on source inspection or mocks.
