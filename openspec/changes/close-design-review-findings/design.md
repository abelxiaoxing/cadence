## Decisions

Environment identity hashes installed bytes, executable modes and dependency links in the cancellable I/O worker. Runner entrypoint currentness is also checked locally. Baseline and phase policy facts include environment identity; changes require rebuilding baseline and revalidating retained evidence. Before/after verification checks reject concurrent drift. Vite temporary caches are excluded.

Structured Gate A accepts a canonical ChangeContract containing goal, stable acceptance IDs with verification obligations, explicit constraints and bounded write/dependency/mode policy. The journal retains normalized authority and inherits it with Gate A. Compilation injects that authority and rejects substitution, missing acceptance and policy expansion. Automatic amendments cannot renew Gate A, replace behavior decisions, or rewrite proposal/spec artifacts. Legacy revisions retain conservative execution obligations; no semantic equivalence claim is made for arbitrary prose.

RecoveryActionRequest carries the kind and attempt facts. The parent checks its lease and chooses the same bounded decision policy for nested affected/cumulative repairs and Red corrections. Candidate launches still reserve through the durable run budget. Executor loops sequence local effects but no longer set independent retry limits; they cannot authorize extra work.

New task verificationMode defaults to behavior. Mechanical/refactor modes require structured authorization; mechanical writes are limited to document/data/config extensions, public behavior impact requires Red, and refactor cannot overwrite accepted verifier inputs. For internal compatibility the compiler retains a readonly baseline slot; the graph, scheduler and ledger begin execution at Green, without generating Red evidence. Existing baseline, affected, cumulative and post-apply checks remain mandatory.

The evaluation CLI uses Pi RPC and verified package prompts in a disposable Git consumer. Preflight never calls a model. Live mode records allowlisted counts/costs and validates final behavior with a separate oracle. Host replacement exercises delivery discovery. Provider failures, cancellation, Design-only completion and stalls never count as successful implementation. No raw conversation is persisted.

## Validation

Permanent regressions cover installed runner drift, transitive dependency identity, environment changes across reopen, structured Gate inheritance/compiler substitution, amendment rejection, shared recovery decisions, nonbehavioral execution and evaluation metrics. Live reports are evidence only for their actual outcome; provider unavailability is not UX acceptance.
