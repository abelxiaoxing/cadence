## Why

The project review found incomplete verification environment identity, model-dependent amendment constraints, distributed recovery decisions, compulsory Red work for nonbehavioral changes, and no live workflow evaluation entrypoint.

## What Changes

- Bind installed dependency and runner content to retained verification evidence.
- Add structured Gate A ChangeContract and constrain automatic amendments.
- Route nested recovery decisions through the parent policy and existing durable reservations.
- Admit explicitly authorized mechanical and behavior-preserving verification modes.
- Add disposable consumer scenarios and safe live-model measurements.

## Impact

Runtime, Design/Implement prompts, current specifications, package manifest and regression coverage change. Historical prose approvals and behavior plans remain readable. Linux Bubblewrap remains the Implement backend.
